# FolderHop 驗證紀錄

## 1.0.5：拖動橙色 Logo 搬動窗口

- 左上角橙色 Logo 改為窗口移動把手，毋須按住 ⌥；其餘區域繼續左鍵拖動 3D 旋轉。
- Logo 命中區使用同一三維投影模型，跟住卡片目前姿態更新；窗口移動事件先於旋轉手勢處理，避免同一次拖動觸發兩個操作。
- 已實機驗證正面 Logo 向左 50 點、向下 80 點搬動，窗口儲存坐標亦相應改變；反向搬動可恢復原位置，搬動過程唔會旋轉卡片。
- 已實機驗證卡片約 46° 側轉後，拖動畫面上嘅橙色 Logo 仍能搬動整個窗口，姿態保持不變。
- 已實機驗證拖動其餘區域仍只旋轉，窗口坐標不變。位置使用本機 frame 儲存，啟動時明確呼叫 setFrameUsingName 還原。最後一次重啟後嘅鼠標復核因 Mac 鎖定而未完成，唔標記為已實機通過。

## 1.0.4：左鍵拖動先旋轉

- 改用 AppKit 左鍵拖動手勢，取消以滑鼠懸停／絕對位置控制角度。新拖動從目前姿態開始，按相對位移累積，支援連續完整翻轉。
- 未按住左鍵時移動滑鼠唔會旋轉；放開後保留姿態，移出面板後回正。拖動中出界會繼續捕捉該次手勢，放開於界外時回正。
- 拖動與普通點擊分開；拖動識別後抑制該次 mouse-up 嘅資料夾／背面按鈕動作，避免放開拖動時誤開目錄。新點擊立即重新允許。
- 按住 ⌥ 拖動頂部可搬動窗口，避免同左鍵旋轉衝突；窗口邊緣仍可縮放。
- 已實機驗證左鍵拖到側面、連續拖到背面、松開後移動／點擊空白處仍保持角度、移出後回正，以及普通點擊背面返回正面。
- 已實機驗證從資料夾條目開始拖動唔會開啟該資料夾（Finder 原視窗保持不變），普通單擊則會在 Finder 正常開啟。
- 26 項核心測試更新並通過，覆蓋拖動起點不跳變、多次拖動累積、反向拖動復原、無效輸入，以及既有立體投影與歷史紀錄功能。

## 1.0.3：有厚度嘅完整 360° 卡片

- 水平／垂直方向均支援由中央到邊緣完整轉一圈，移開後以無回彈過衝嘅動畫回到正面。
- 採用 18 點厚度嘅實體圓角側壁、獨立正面／背面同共用三維透視模型；唔係只放大舊版平面傾斜角度。
- 正面繼續顯示最近 5 個資料夾，背面顯示 FolderHop 品牌同私隱提示；背面點一下可以停回正面，方便點擊資料夾。
- 實體側壁由圓角輪廓逐段擠出，按三維法線剔除背向側面，加入金屬邊緣高光。互動正背面與側壁使用同一投影，避免層與層錯位。
- 以八個立體角點計算適配比例，任何旋轉方向均保持喺透明窗口內；預留陰影空間。
- 已實機檢查 90° 厚邊、180° 獨立背面、270° 對側厚邊、接近 360° 返回正面，以及斜視側壁厚度。
- 已實機檢查鼠標移出後回正、點擊背面返回正面，以及回正後一鍵開啟 Finder 資料夾。
- 測試增至 **26 項，0 失敗**，包括全周轉角、正背面可見性、側視厚度、多方向角點不裁切、互動面與立體側壁投影一致、無效輸入同完整轉一圈後幾何一致。
- 鼠標操作沿用 DEBUG 同內容預覽，正式版繼續只顯示喺桌面、無選單列或 Dock 圖示。

## 1.0.2：純桌面 3D 面板

- 移除 NSStatusItem／選單列圖示、獨立快捷面板同全域快捷鍵；保留桌面面板右上角設定入口。
- 仍只展示最近 5 個有效資料夾；保持無 Dock 圖示同桌面層級。
- 加入最多上下 6°、左右 8° 嘅 3D 傾斜，同滑鼠高光、陰影及移出回正。系統「減少動態效果」會停用傾斜。
- 只處理本窗口嘅滑鼠事件，無全域輸入監控或額外定時器。
- 3D 內容周圍預留透明邊距，避免轉動時裁切玻璃邊緣。滑鼠追蹤範圍保持固定，避免邊緣反覆進出造成抖動。
- 已實機檢查左右角落傾斜、移出後回正，以及傾斜時以滑鼠點擊資料夾並在 Finder 開啟。
- 自動化工具無法向桌面層窗口發送座標操作，因此上述鼠標互動測試使用 DEBUG 預覽嘅同一份面板內容，唯一差異係窗口層級。正式 Release 唔包含預覽入口，仍固定喺桌面層。
- 核心測試增至 **20 項，0 失敗**，新增傾斜中心對稱、幅度限制、無效座標及零尺寸處理。

## 驗證範圍限制

- Carbon 全域快捷鍵已成功註冊，App 內快捷鍵呼出與面板鍵盤流程已實測。GUI 自動化對其他 App 發送嘅按鍵有目標程序限制，未當作硬體鍵盤跨 App 快捷鍵已驗證；建議使用者喺其他 App 親按設定組合確認。
- 權限拒絕分類有單元測試，亦有實際權限預檢／拒絕引導實作；無為咗測試而撤銷使用者現有 Finder 自動化權限，完整拒絕／恢復流程仍需人工驗證。
- 無實際拔插多個顯示器，亦無改動使用者登入項目、系統深淺色外觀或測試所有 Spaces／Stage Manager 組合。
- 最低系統版本為 macOS 14；今次執行環境係 macOS 26，唔聲稱已喺 14／15 實機驗證。
- 輪詢間隔內嘅快速目錄跳轉可能漏記；無宣稱取得啟用前歷史或全系統完整導航。

更完整嘅已知限制、權限設定與使用方法見根目錄 README。
